# kalcode

A coding harness that runs entirely on free tiers.

kalcode speaks the [Agent Client Protocol](https://agentclientprotocol.com) (ACP), so it spawns
coding agents you have already logged into (opencode, freebuff, cline, gemini, goose, whatever
speaks ACP) and drives them from one place. One agent orchestrates a thread and delegates subagent
work out to the others, so a single exhausted free quota never stalls you.

No API keys held by kalcode. No subscriptions. Each agent does its own auth.
